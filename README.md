## Experimentation
### Setting up environment
The environment can be reproduced using the `pyproject.toml` file provided. The file should support Linux, Windows, and MacOS systems.
For a brief guide on using `uv` to recreate the environment, see [Using UV to reproduce environments](./uv-environments.md).

**NOTE:** Python 3.12 is the recommended version of Python.

### Downloading Data
There are three datasets used in this repository. Below is a brief guide to downloading these datasets locally.

#### 1. Proportion MNIST Bags Data
The proportion MNIST bags dataset is created using the MNIST dataset, available from the `torchvision` package (`torchvision.datasets.MNIST`)  
The proportion MNSIT bags dataset is created in the `experiment-promnist-bags.py` script.

#### 2. CAMELYON16 \& UNI2-H Embeddings
Downloading the CAMELYON16 whole slide images requires the `awscli` tool. This can be installed via `pip`. The data can then be downloaded into a specified folder using the following:
```
$ aws s3 cp --no-sign-request s3://camelyon-dataset/CAMELYON16/ ./dataset/camelyon16/ --recursive
```
where `./dataset/camelyon16` is the destination where the data should be copied to.

Once the WSI data has been downloaded, UNI2-H embeddings can be generated by running the following scripts:
1. `utils-autodetect-tissue-wsi.py` - detects H&E-stained tissue and generates polygon coordinates which surround the detected tissue.
```
$ python experiments/utils-autodetect-tissue-wsi.py -d "D:\Data\CAMELYON16\images" -t "*.tif*" -l 7
```
2. `utils-zarrify-wsi.py` - converts WSIs into a collection of image patches (full resolution) as a `.zarr` file/directory
```
$ python experiments/utils-zarrify-wsi.py -d "D:\Data\CAMELYON16\images"
```
3. `utils-download-uni2-h.py` - download UNI2-H model from huggingface (requires huggingface token). **Note:** [`MahmoodLab/UNI2-h`](https://huggingface.co/MahmoodLab/UNI2-h) is a *gated* model on HuggingFace — you must request access on its model page and be approved before this script's token will work. Access requests are typically approved quickly, but budget time for this before running the embedding step.
4. `utils-uni2-embedding.py` - converts image patches contained in `.zarr` directories as bags of embedding vectors.

#### 3. Prostate Cancer LDO Dataset
[![DOI](https://img.shields.io/badge/DOI-10.5281%2Fzenodo.21983424-blue)](https://doi.org/10.5281/zenodo.21983424)  
LDO features are computed from segmented nuclei of Feulgen-thionin stained prostate core needle biopsies.
The collection of features for each patient can be accessed above.
After download, the data should be formatted in the following manner:
```
data_folder/
    |-- Tensors/
    |-- |-- 115.csv
    |-- |-- ...
    |-- clinical_deidentified_filtered.csv
```
The location of `data_folder` should be saved in the `.env` file.

### **Proportion MNIST Bags**
#### 1. Proportion MNIST Bags Experiment
This script (`experiment-promnist-bags.py`) runs the full experiment, from dataset creation to training ABMIL classifiers, computing correlation between instance logit and its attention weight.
Saves relevant results data to `promnist.csv` file.
This script should be run first.

#### 2. Proportion MNIST Bags - Instance Logit & Attention
This script (`experiment-promnist-za-dists.py`) creates another `.csv` file to be used for plotting instance attention against instance logit for specific datasets with different $\tau$ values.
This relies on the datasets created in the part above, so should be run after (`experiment-promnist-bags.py`).

### **UNI2-H CAMELYON16 Embeddings**
#### 1. CAMELYON16 Embedding Generation
Instructions for downloading and processing data prior to training ABMILite is outlined [here](#2-camelyon16--uni2-h-embeddings).

#### 2. Training ABMILite on UNI2-H Embeddings
Once UNI2-H embeddings are generated for all patches extracted from the CAMELYON16 slides, `experiment-uni2-camelyon16-abmil.py` can be used to train the ABMILite.

#### 3. Bootstrapped Uncertainty of Instance-level Scoring
Once ABMILite has been trained, `experiment-camelyon-uncertainty.py` bootstraps (slide-level resampling) the patch-level ROC-AUC of attention, instance logit, and a Bayesian Gaussian Mixture cluster score, reporting confidence intervals plus a repeated-measures ANOVA/Tukey HSD comparison across the three. This is the script that produces the bootstrap-CI/statistical-testing results reported in the manuscript.

#### 4. Attention Overlay Viewer (optional)
`figures-camelyon16-attention-overlay.py` is an interactive [napari](https://napari.org/) viewer that overlays a trained ABMILite checkpoint's per-patch attention and instance-logit scores directly on a WSI, for qualitative inspection. It does not save any files; it's for visual exploration only.

### **Large-scale DNA Organization (LDO) for Prostate Cancer**
#### 1. LDO Feature Selection
Use the `utils-ldo-feature-selection.py` script to remove features with redundancies (high Pearson correlation `>0.9`). This will create a new folder within the data directory called `filtered_copy`. The newly created files will be used in model training.

#### 2. Prognosis via Attention-based LDO Analysis
Use the `experiment-ldo-abmilite-training.py` script to train ABMILite model, save its weights along with creating figures for manuscript.
